# 🐙 Лаборатория Осьминога

Проверка торговых стратегий против случайности.

Бэктест отвечает, сколько стратегия заработала бы. Он не отвечает на главный
вопрос: **отличим ли результат от случайности на тех же данных.** Каждая
стратегия здесь прогоняется против двух независимых нулей (тайминг и отбор),
с поправкой на множественность и с воротами прибыльности.

Мы публикуем и провалившиеся проверки — из четырёх стратегий три не подтвердились.

- Данные: `lab.json` (результаты прогонов), `trades.json` (публичный портфель).
- Движок: каталог `lab/` в основном репозитории. Стратегия описывается спекой JSON, не кодом.
- Перед каждой публикацией обязателен `python site/guard.py` — приватный гард.

Разбор, а не сигнал. Не инвестиционная рекомендация.
